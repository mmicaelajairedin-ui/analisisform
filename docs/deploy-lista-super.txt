LISTA DEL SÚPER (IA) — CÓMO ACTIVARLA
=====================================

1) Desplegar la función nueva (en tu compu, con Supabase CLI):

   supabase functions deploy lista-super --no-verify-jwt


2) La API key ya está puesta (la usan tus otras funciones de IA),
   así que NO hace falta configurar nada más.


3) Verificar que quedó:

   supabase functions list

   Tiene que aparecer "lista-super" en la lista.


LISTO. Apenas se despliega, la lista del súper funciona para todos
los clientes (incluido el demo de María), en Portal > Nutrición.


-------------------------------------------------
OPCIONAL — abaratar el modelo de IA
-------------------------------------------------
En el archivo  supabase/functions/lista-super/index.ts
cambiá esta línea:

   const CLAUDE_MODEL = "claude-opus-4-8";

por:

   const CLAUDE_MODEL = "claude-haiku-4-5";

(Haiku es más barato y rápido; alcanza de sobra para esta tarea.)
Después volvé a correr el deploy del paso 1.
