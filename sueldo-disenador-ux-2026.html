Qué mueve el sueldo de un diseñador

  • Tipo de empresa. Empresas con cultura design-led (Stripe, Linear, Notion, Figma) pagan 20-30% más. Agencias tradicionales son el suelo.
  • Scope: visual vs producto. UI Designer puro cobra menos que Product Designer (research + UX + UI + colaboración con dev y producto). El salto suele venir con +30-40% de sueldo.
  • Design systems y operaciones de diseño. Especialistas senior en design systems, tooling y design ops cobran tope-de-mercado. En USD remoto, 130-160k.
  • Industria. Fintech, dev tools y B2B SaaS: techo. E-commerce y media: medio. Agencias: suelo.

UX vs UI vs Product Designer: cuál cobra más

  • UI Designer puro: visual, design systems junior, componentes. Suelo o medio del rango.
  • UX Designer: research, wireframes, prototipado, user flows. Rango medio.
  • Product Designer: rol amplio — research + UX + UI + colaboración con producto y dev. Techo del rango.
  • UX Researcher: rol especialista. Rangos similares a Senior PM.
  • Design Systems Lead: rol mejor pago de diseño. En USD remoto: $130-180k senior+.

El portfolio sigue siendo el determinante #1

En diseño, el portfolio explica mejor el rango que el CV o los años. Un Product Designer con 3 años pero portfolio fuerte (B2B real, design systems, casos con métricas) puede negociar como senior.

Lo que más mueve el portfolio en 2026:

  • Casos con contexto de negocio y métricas (no solo screens bonitas).
  • Procesos visibles: research → decisiones → iteraciones → resultados.
  • Colaboración cross-functional con producto, dev, data.
  • Para senior+: ownership de un sistema o área completa.

Cómo usar estos rangos en una entrevista de diseño

  • Aclara el scope antes de hablar de números. Si el título es "UX Designer" pero las responsabilidades son de Product Designer, el rango cambia +30%.
  • Si te preguntan el rango: "Para roles de Product Designer en este alcance, mi rango está entre [mínimo] y [máximo]."
  • Negocia tools y formación. Figma Pro, Maze/Lookback, conferences. España: ~1.500-2.500 €/año. USD remoto: $2.500-5.000.
  • Tu portfolio abre la puerta, pero el CV pasa el filtro. Optimiza tu CV para ATS con IA en CV Express antes de aplicar.
